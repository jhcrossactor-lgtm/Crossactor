# Adobe 請求書・領収書 ダウンロード＆印刷スキル（手動実行）

## 起動方法

ユーザーが **`adobe`** と入力したら即起動。対象月の指定がなければ **先月分** を対象とする。
（例：`adobe` / `adobe 2026-05` / `adobe 今月分`）

起動したら、まず1行で対象を宣言してから着手する：
「先月分（YYYY-MM）のAdobe請求書・領収書を取得して印刷するで。」

## 前提条件
- Claude in Chrome が起動済み（デスクトップアプリ接続済み）
- Chrome に Adobe アカウントがログイン済み（または認証情報保存済み）
- computer-use でエクスプローラーへのアクセス許可が得られること
- 印刷する場合：`C:\Users\hosokawa\Desktop\invoice_print.py` が配置済み

---

## 手順

### Step 0: 対象月の確定
- ユーザー指定があればそれに従う
- 指定なし → 実行日の**前月**（YYYY-MM）

### Step 1: 請求履歴ページへ直アクセス

```
navigate: https://account.adobe.com/billing-history?lang=ja
```

- **ログイン済み** → そのまま Step 2 へ
- **ログイン画面が出た** → **ユーザーにログインを依頼して待機**（パスワードは絶対に代行入力しない）
- **請求履歴が出ない** → 左サイドバー「プランと支払い」→「請求履歴」

### Step 2: 対象プランと対象月を確認

- 対象：**Illustratorプラン** と **Photography plan (20GB)** の両方
- 対象行に「請求書（控え）」「領収書」のダウンロードリンクがあることを確認
- 請求未確定でPDFリンクが表示されない場合は、その旨を記録し翌日以降の再試行を案内する（無理に進めない）

### Step 3: PDFをダウンロード

- 請求書・領収書は別ファイルの場合があるため**両方**取得（最大4ファイル）
- ダウンロード先は既定（デスクトップ）のままでよい。ファイル名はブラウザの既定命名のまま
  （`invoice.pdf`, `invoice (1).pdf`, `invoice (2).pdf`, `invoice (3).pdf` の形式でデスクトップに保存される）
- リネームや整理は不要（Step 4 の印刷スクリプト側で `invoice*.pdf` を自動処理する想定）
- ダウンロード完了を確認してから次へ

### Step 4: 印刷（ユーザーが希望する場合のみ）

**印刷するかを必ず確認してから実行する。**

実行はcomputer-use経由でデスクトップの `invoice_print.py` を呼び出す方式：

1. computer-use で「エクスプローラー」へのアクセスを `request_access` で許可してもらう
2. エクスプローラーを開き、アドレスバーをクリックして次のコマンドを入力しEnterで実行する：
   ```
   python "C:\Users\hosokawa\Desktop\invoice_print.py"
   ```
3. **PowerShellやターミナルアプリ（Windows Terminal等）は直接キー入力ができないため使用しないこと。**
   必ずエクスプローラーのアドレスバー経由で python コマンドを実行する
4. ファイルのリネームや整理は不要（`invoice_print.py` 側で `invoice*.pdf` を自動的に処理する想定）

**エラー時の扱い：**
computer-use のアクセス許可が得られずエラーになった場合は、無理に続行せず
「ダウンロードは完了したが、印刷ステップはアプリアクセス許可が必要なため未実行」と報告して終了する。
右クリックでの個別印刷など手動操作での代替は行わない（`invoice_print.py` の実行のみで完結させる）。

### Step 5: 完了報告

- ダウンロードしたファイル名とパス
- 各プランの請求金額（PDF記載分）
- `invoice_print.py` の実行結果（成功/失敗）
- PDFが未確定で取得できなかった場合はその旨と再試行の目安

---

## 注意事項

- **パスワードは絶対に代行入力しない**
- スケジュール実行はしない（手動トリガー専用）
- 「請求書」と「領収書」は別PDFの場合あり、両方取得
- 複数プラン契約分は全て取得
- 印刷は `invoice_print.py` の実行のみで完結させる。右クリックでの個別印刷など手動操作は行わない
- Adobe側UI変更時はページ内検索で対応

## トラブルシューティング

| 状況 | 対処 |
|------|------|
| ログイン画面が表示される | ユーザーにログインを依頼して再開 |
| 請求履歴ページが見つからない | `account.adobe.com` トップからメニューを探す |
| PDFリンクが表示されない | 請求未確定の可能性。翌日以降に再試行を案内 |
| ダウンロードがブロックされる | Chromeのダウンロード設定確認を案内 |
| computer-use のアクセス許可が得られない | 印刷ステップのみ未実行として報告し、無理に続行しない |
| Claude in Chrome / デスクトップアプリ未接続 | 手動実行にはデスクトップアプリの接続が必要。接続後に再度 `adobe` と入力して起動 |

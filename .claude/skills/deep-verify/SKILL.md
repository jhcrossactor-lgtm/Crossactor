# 深層検証（逐次マルチロール）

チャットは並列サブエージェント不可のため、**5役割を逐次シミュレート**する。各役割は前の役割の出力を読み、独立した立場で発言する。役割間で安易に同調しないこと。

## モード選択

- **debate**（デフォルト）：トレードオフのある判断・設計選択 → 役割が論点で対立→収束
- **poll**：計算・事実確認・ハルシネーション検出 → 各役割が独立に検算→集約

## 5役割

1. **起案者**：対象の主張・計算・判断を明示的に再構成（前提・数式・根拠を全部書き出す）
2. **批判者**：前提の誤り・見落とし・エッジケースを最低3点指摘（見つからなくても探す姿勢を崩さない）
3. **検算者**：数値・法規・事実を独立ルートで再導出（元の手順をなぞらない。別解で検算）
4. **実務者**：一級建築士・実務23年の視点で現実整合性チェック（役所協議・施工・商慣行で通るか）
5. **裁定者**：1〜4を統合し、確度（高/中/低）+ 残リスク + 修正版を出力

## イテレーション

- 裁定者が「要修正」と判断したら、修正版を起案者に戻して次イテレーション
- 最大3回。3回で収束しなければ **DONE_WITH_CONCERNS** として未解決点を明示

## 構造化出力（必須）

各役割の発言は以下の形式：
```
【役割名】
主張：
根拠：
懸念/指摘：
```

最終出力：
```
## 検証結果
- 結論（修正版）：
- 確度：高/中/低
- 主要な修正点：
- 残リスク：
- 役割間で本当に対立した論点：
```

## 禁止事項（アンチパターン）

- **偽コンセンサス**：対立が残っているのに合意を装う。対立は対立のまま報告
- **外れ値の隠蔽**：1役割だけ異論がある場合、それを消さず明記
- **曖昧な対象への起動**：検証対象が曖昧なら、まず対象を1文で確定してから開始
- **検算の手順なぞり**：検算者が元の計算手順をコピーして「合ってる」と言うこと。必ず別ルート

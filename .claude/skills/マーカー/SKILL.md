# 宅建テキスト マーカー付与

NotebookLM の宅建講習ソース（音声講義）を聞き、講師が指示したマーカー箇所を
テキストPDFにハイライト注釈として焼き込む。出力はマーカー版PDFと照合CSV。

## 前提（ローカル実行専用）

このスキルはローカルPCでしか動かない。クラウドセッションでは実行不可。

- **NotebookLM** にログイン済みのブラウザ（ノートブック名：**宅建講習**）
- **Google ドライブ デスクトップ** がマウント済み
- **Python 3** と **PyMuPDF**（`pip install pymupdf`）

クラウドから頼まれた場合は「ローカルでやる必要がある」と即答し、進めない。

## 手順

### 1. 未処理の音声を特定する

作業フォルダの `processed_audio.txt` を読む。NotebookLM「宅建講習」のソース一覧と
突き合わせ、**まだ載っていない音声**だけを対象にする。処理済みを再処理しない。

2026-09-18 時点の処理済み12本：
民法第1回 講義1／講義2、民法第2回 講義1／講義2、宅建業法 1-1・1-2・2-1・2-2・3-1・3-2・4-1・4-2

### 2. 音声を聞いて指示を拾う

対象音声を頭から最後まで聞き、次の2種類を拾う。**聞いた範囲だけ書く。推測で埋めない。**

**(a) マーカー指示** — 講師が線を引けと言った箇所

> 「線引いといてください」「マーカー引いて」「ここ大事」「ここ出ます」「アンダーライン」
> 「赤で囲って」「チェックしといて」

**(b) 飛ばし指示** — 出題されないので読まなくてよい箇所

> 「ここは出ません」「飛ばしてください」「読まなくていい」「参考程度」

講師が言ったページ番号は**印刷ページ**（PDFのページ番号ではなく紙面下端の数字）。
そのまま書く。変換しない。

### 3. marks_*.txt に追記する

既存の末尾に追記する。**既存行は消さない・並べ替えない。**

```
# 民法第3回 講義1
29|追認したものとみなす
35|債務者の責めに帰すことができない事由によるものであるときは、損害賠償請求はできない
```

- `# ` 行 = セクション見出し。音声1本につき1つ、`# <科目><回> <講義名>` の形式
- 本文行 = `印刷ページ|文言`
- **文言はテキストの原文をそのまま写す**。講師の言い換えではなく紙面の文字列。
  スクリプトが原文と突き合わせるため、ここがズレると当たらない
- 長すぎる文言は当たりにくい。1文（20〜60字程度）に収める
- 該当なしの回は `# 見出し` だけ書いて本文行を書かない

### 4. skip_*.txt に追記する

```
印刷ページ|範囲|理由|音声
```

- `範囲` は `全部` か、紙面上の範囲（例：`第3節`）。`全部` ならページ右上に赤×のみ、
  範囲指定ならその文字列＋「のみ」のラベルが付く
- `理由` は講師の発言要旨（例：`出ない`）
- `音声` はセクション見出しと同じ音声名
- 4列ちょうど。列が合わない行は無視される

### 5. スクリプトを実行する

```powershell
python "<このスキル>\scripts\add_markers.py" `
  --work "G:\google drive_jh\claude\成果物\宅建テキストマーカー" `
  --src  "G:\マイドライブ\宅建テキスト"
```

環境変数 `MARKER_WORK` / `MARKER_SRC` でも指定できる。
対象PDFを増やす・変えるときは作業フォルダに `jobs.json` を置く（既定より優先）：

```json
[{"marks":"marks_minpo.txt","skip":"skip_minpo.txt",
  "src":"26宅建_テキスト(民法等)完版.pdf",
  "dst":"26宅建_テキスト(民法等)完版_マーカー版.pdf","offset":15}]
```

**実行前にマーカー版PDFを閉じておく。** 開いたままだと上書きできず `.tmp` に落ちる。

### 6. 照合結果を確認する

`マーカー照合結果.csv` の「結果」列を見る。

| 結果 | 対応 |
|---|---|
| `一致` | そのまま |
| `近似一致（0.xx）` | 0.85未満は該当ページを目視。誤爆していたら marks の文言を原文に直して再実行 |
| `＊要確認（本文に見つからず）` | **必ず潰す。** ページ番号違いか文言の写し間違い。直して再実行 |

`＊要確認` が残ったまま完了報告しない。件数と内訳をほせもやんに出す。

### 7. processed_audio.txt に追記して完了

処理した音声名を NotebookLM のソース表記どおりに追記する。
成果物（マーカー版PDF・CSV2本・marks/skip/processed の更新）は作業フォルダ＝Drive上に
保存されるので、そのまま同期される。

## 動作の仕組み（デバッグ用）

- **ページ対応**：各ページ下端60pt以内の数字を印刷ページ番号として読み、
  印刷ページ→PDFページの対応表を作る。章扉など番号が無いページは予備オフセットで補う。
  目次の数字を拾わないよう、想定ずれ幅から±3を超える番号は捨てる
- **文言照合**：空白・句読点・括弧・記号を落として突き合わせる。完全一致がなければ
  同じ長さの窓をずらして類似度0.75以上を採用。6字未満は近似照合しない
- **表記ゆれ吸収**：`脅迫→強迫`、`関わらず→かかわらず`、`合わせて→併せて`
- **探索範囲**：指示ページ → +1 → −1 の順に探す
- **注釈**：マーカーは黄色ハイライト、飛ばしは右上に赤×＋範囲ラベル

## やらないこと

- 音声に無い箇所を「重要そうだから」で勝手にマークしない
- 既存の marks/skip 行の削除・書き換え（明示の指示がある場合を除く）
- 元PDF（`--src` 側）への書き込み。出力は必ず作業フォルダ側

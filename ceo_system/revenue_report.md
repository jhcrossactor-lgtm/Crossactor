# 収益報告の手順（Cro）

ほせもやんの Notion 収益管理DBを読んで報告する。数字は必ず DB から取る。推測・補完はしない。

## 読みに行く先（Notion）
| DB | データソースURL | 主なプロパティ |
|---|---|---|
| 売上DB | `collection://531472f9-d415-4c0b-bfc1-ffa6e5947bef` | 案件名 / クライアント / 種別 / ステータス（見積・請求済・入金済）/ 請求日 / 入金日 / 金額（税抜）/ 備考 |
| LINEスタンプ売上DB | `collection://94ec9cc4-78b8-4dd3-ab6a-869897ccda14` | 行名 / アイテム / 種類 / 対象月 / 販売数 / 送信数 / 売上（分配額）/ 区分（速報・確定）/ 売上DB への relation |

- 売上DB ページ: https://app.notion.com/p/0b8e77e83b894876bf7ce30908dd8b6a
- LINEスタンプ売上DB ページ: https://app.notion.com/p/f9727d1f1eac4927a4d123feb0792e56
- 取得は Notion MCP `notion-query-data-sources` の rows モード（view モードも可。SQL は無料プランの上限あり）

## 報告フォーマット
```
【収益報告】YYYY-MM-DD 時点

■ 今月（請求日ベース）
・請求済＋入金済 合計：¥N（税抜） / 件数
・内訳：クライアント別・種別別（金額の大きい順）

■ 未入金（ステータス=請求済）
・案件名 / クライアント / 金額 / 請求日 / 経過日数

■ 見積中（ステータス=見積）
・案件名 / クライアント / 金額

■ 累計（入金済）
・年初来 / 全期間

■ LINEスタンプ
・対象月ごとの販売数・分配額（速報／確定を区別）

■ Croの所見
・気づき1〜3点（要確認事項、入金遅れ、DB未入力の疑い など）
```

## ルール
- 「未入金」は 請求済 かつ 入金日が空 のもの。請求日から30日超は赤字で注意喚起
- 備考に「要確認」がある行は所見で必ず拾う
- DB が空・行が少ない場合はその旨を書く。数字を作らない
- 顧客名は DB に入っている表記をそのまま使う（画面表示用の匿名化はしない。報告先はほせもやんのみ）

# 収益報告の手順（Cro）

ほせもやんの Notion 収益管理DBを読んで報告する。数字は必ず DB から取る。推測・補完はしない。

## 読みに行く先（Notion）
| DB | データソースURL | 主なプロパティ |
|---|---|---|
| 売上DB | `collection://531472f9-d415-4c0b-bfc1-ffa6e5947bef` | 案件名 / クライアント（LINE・A8・note・その他）/ 種別 / ステータス / 請求日 / 金額（税込）/ 備考 |
| LINEスタンプ売上DB | `collection://94ec9cc4-78b8-4dd3-ab6a-869897ccda14` | 行名 / アイテム / 種類 / 対象月 / 販売数 / 送信数 / 売上（分配額）/ 区分（速報・確定）/ 売上DB への relation |

- 売上DB ページ: https://app.notion.com/p/0b8e77e83b894876bf7ce30908dd8b6a
- LINEスタンプ売上DB ページ: https://app.notion.com/p/f9727d1f1eac4927a4d123feb0792e56
- 取得は Notion MCP `notion-query-data-sources` の rows モード（view モードも可。SQL は無料プランの上限あり）

## 集計ルール（2026-09-27 ほせもやん指示）
- **請求額＝売上。入金は追わない。** 請求日ベースで月次集計する
- ステータス「見積」は売上に含めず「見込み」として別枠
- 請求日が空の行は集計から漏れるので、報告で指摘する
- 備考に「要確認」がある行は所見で必ず拾う
- DB が空・行が少ない場合はその旨を書く。数字を作らない
- 顧客名は DB の表記をそのまま使う（報告先はほせもやんのみ）

## 報告フォーマット
```
【収益報告】YYYY-MM-DD 時点（税込・請求日ベース）

■ 今月の売上：¥N / 件数（内訳：案件／クライアント／種別）
■ 先月：¥N / 件数
■ 年初来：¥N（クライアント別・種別）
■ 累計：¥N
■ 見積中（見込み）：¥N / 件数
■ LINEスタンプ：直近の対象月の販売数・分配額（速報／確定）
■ Croの所見：要確認事項、請求日未入力、未入力の疑い など1〜3点
```

`cross/supabase/functions/_shared/notion_revenue.ts` が同じルールで要約を作り、クロスが声で答える＋画面に収益サマリーを出す。

## 2026-08-06 — Claude資産の分類方針

**決定：** Claude上の全業務資産を Skill / Agent / Plugin / CLAUDE.md に分類し、
まず構造是正のみを実行する。新規スキル作成とPlugin化は次フェーズに回す。

**理由：** 重複したディレクトリを残したまま新規作成すると、どちらに作るかで再び分岐する。
構造を確定させてから足す。

**却下した選択肢：**
- 一気にPlugin化まで実行する → 変更量が最大になり、個人環境の再インストールも必要。
  構造是正の効果検証ができないまま次の変更が乗る
- 分類だけして実行しない → `ai-editorial` / `ai-employee` が動かない状態が続く

**根拠資料：** `organization/claude-assets-classification.md`

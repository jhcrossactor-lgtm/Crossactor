## 決定ログ

### 2026-09-16｜外部リンクは公開URL形式か必ず確かめる
- **決定**：LPのCTAは `https://www.lancers.jp/profile/Crossactor`（公開プロフィール）を使う。**解決済み**
- **理由**：最初に渡された `lancers.jp/mypage/profile?ref=...` は本人専用のログイン必須領域で、第三者が踏むとログイン画面に飛ぶ。`?ref=` は内部トラッキング用パラメータ
- **却下した選択肢**：渡されたURLをそのまま貼る → 壊れていることに気づけないまま見込み客を失う
- **教訓**：外部リンクを貼る前に「**ログアウト状態で開いて成立するか**」を必ず確認する

### 2026-09-16｜LPのコントラストはブランド変数ごと是正した
- **決定**：`--ink-muted` `#7a7570`→`#66615b`、`--accent` `#8b6914`→`#856312` に変更。全テキストをWCAG AA（4.5:1）以上へ
- **理由**：最低値が1.73:1で、操作説明文すら読めない状態だった。個別上書きより変数を直す方が再発しない
- **却下した選択肢**：`--accent` を据え置き、`.usecase-tag` だけ font-weight で補強 → 一貫性が崩れる
- **要確認**：ブランドガイドでゴールドの色値が固定されているなら差し戻す

### 2026-09-16｜AI秘書は「下書きまで」を既定にする
- **決定**：`slack_send_message`（即時送信）は通常フローから除外。既定は「下書き作成 → ほせもやんが自分で送る」。送信・予定作成・削除は1件ずつ明示承認
- **理由**：Slack MCPはユーザートークン動作で、**投稿がほせもやん本人名義で出る**。誤爆の損失が最大
- **却下した選択肢**：確認プロンプト付きの自動送信 → 承認疲れで素通りするだけ。構造で防ぐ方が確実
- **補足**：Gmail MCPには送信ツールが存在しないため、Gmail側は構造的に下書き止まり

### 2026-09-16｜共通ルールの正本は AGENTS.md
- **決定**：ミッション・人格・組織・規約・命名・コマンド・出力ルール・行動制約は全て `AGENTS.md` に集約。CLAUDE.mdは `@AGENTS.md` ＋ Claude固有（Skills索引・Subagents・Permissions）のみ
- **理由**：ツールを増やすたびに同じルールを書き写す状態を断つ
- **却下した選択肢**：CLAUDE.mdを正本のまま維持 → Claude以外のエージェントがルールを読めない
- **付随**：`AGENTS.MD`（拡張子が大文字）は `AGENTS.md` にリネーム。Linuxでは別ファイル扱いになり、ツールに拾われなかった

### 2026-09-16｜第三者スキルは監査してから、必要な分だけ入れる
- **決定**：導入前にリポジトリとインストーラの中身を読む。インストーラのテレメトリは `DO_NOT_TRACK=1 DISABLE_TELEMETRY=1` で無効化する。必要なスキルだけスコープ指定で入れる
- **理由**：`skills` CLI は匿名テレメトリを送る（送信内容はバージョン・エージェント名・スキル名のみで、認証情報は含まない）。入れてから消す運用はゴミが残る
- **却下した選択肢**：全部入れてから不要分を削除 → `skills-lock.json` に残骸が残る

### 2026-09-16｜作業前バックアップはコミットしない

- **理由**：バックアップをリポジトリに混ぜると履歴が汚れる。gitに履歴がある以上、恒久保存は不要

`claude mcp add` は成功したが、`claude mcp list` は `! Needs authentication`。
直接検証したところ、認証以前にネットワークが遮断されていた。

```
connect_rejected: gateway answered 403 to CONNECT — host: inspomcp.dev:443
```

Claude Code on the web の egress ポリシーが `inspomcp.dev` を許可していない。
→ **Inspo MCP はローカル実行時のみ利用可能**と結論。

### 判断：synced ディレクトリは永続しない

`~/.claude/skills/synced/` は claude.ai アカウントのスキルを一方向ミラーしたもの。
ここを書き換えてもアカウント側には戻らず、コンテナ消滅で消える。
→ 貼り付け用テキスト（a）とリポジトリへのコミット（b）の両方を提案。

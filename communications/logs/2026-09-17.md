# 2026-09-17

## ヴィラPR動画パイプライン構築（社内テスト）

### ほせもやんからの指示
写真とMOVから16:9のPR動画（約35秒）を作るパイプラインを Python + ffmpeg で構築。
画像＝OpenAI画像編集API、動画＝Gemini Omni 1.1 Flash または MiniMax H3（config切替）。
素材は Google Drive の `★ Crossactor / AI関連 / test`。
モデル名・エンドポイントは推測せず最新ドキュメントで確認すること。

### Croの判断・実施
`pv_pipeline/` にCLIとして実装。カット単位で再実行でき、`cuts.yaml` の差し替えだけで
別物件に流用できる構成にした。工程3（目視確認）は stage2 への進入ゲートとして実装。

### 環境の制約（重要）
このクラウド実行環境の egress ポリシーが以下を拒否する。
- `api.openai.com` → CONNECT 403（画像編集APIに到達不可）
- `api.minimax.io` / `platform.minimax.io` → 到達不可
- `developers.openai.com` / `ai.google.dev` / `docs.cloud.google.com` → 到達不可
- 到達できたのは `generativelanguage.googleapis.com` と `cloud.google.com` のみ

→ **stage1（人物合成）と stage2（動画化）の実行はローカルでやる必要がある。**
　 パイプラインの配線は mock プロバイダで通しで検証済み（`scripts/selftest.sh`）。

### 確認したエンドポイント
- 画像: `POST https://api.openai.com/v1/images/edits`、モデル `gpt-image-2.5-sunburst`
  （2026-09-08リリース）。サイズ `2048x1152` は 16:9 かつ 16の倍数制約を満たす。
- 動画: `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:predictLongRunning`
  → `GET /v1beta/{operation.name}`。Gemini API 公式ディスカバリドキュメントで確認済み。
- MiniMax H3: 公式ドキュメントに到達できず**未検証**。config で差し替え可能にして明示。

### 決定事項
1. 完成尺は約31.5秒になる（36秒 − ディゾルブ0.5秒×9）。35秒に寄せるなら
   `xfade_duration` を下げるか `duration` を足す。ほせもやんの判断待ち。
2. 音楽は無音で出力する。BGMを単体生成する公開APIが無いため（Gemini API v1beta の
   ディスカバリに音楽生成モデルは存在しない）。音源を渡せば `--music` で載せられる。
3. Drive の素材は HEIC のままなので、パイプライン側で HEIC→JPEG 自動変換を入れた。
4. cut01 は「人物なし」だが画像編集は通す（16:9化のため）。cut08 は指示どおり編集スキップ。

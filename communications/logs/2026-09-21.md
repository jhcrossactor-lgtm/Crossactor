### ②正規化の統一（ほせもやん承認：①②の両方）

`scripts/_norm.py` を新設し、`add_markers.py` と `hunt.py` が同じ `norm()` を共有するようにした。

**NFKC は使わなかった。** `add_markers.py` はPDFの文字を1文字ずつ正規化して bbox と
対応付けるため、1文字が2文字以上に展開される変換（`㍉`→`ミリ`）をかけるとハイライトの
座標がズレる。幅そろえは **1文字→1文字** のものだけに限定した。
不変条件（全印字可能文字で `len(norm(c)) <= 1`）をテストで確認済み。

吸収するもの：表記ゆれ（脅迫→強迫ほか）／空白・約物／マークダウン記号 `* _ | #`／
文字幅（`５％`→`5%`、`Ａ`→`A`、`ヶ`→`か`）。

**実害ケース6件で検証した結果：**

| ケース | 統一前 | 統一後 |
|---|---|---|
| 脅迫 ⇔ 強迫 | 一致 | 一致 |
| コンクリート（長音符） | 一致 | 一致 |
| `5%` ⇔ `５％` | **外す** | **一致** |
| `1か月` ⇔ `1ヶ月` | **外す** | **一致** |
| `**太字**` 混入 | **外す** | **一致** |
| 対照（元から一致） | 一致 | 一致 |

**新たに当たるようになったのが3件、外すようになった退行はゼロ。**
合成PDFでエンドツーエンドも通過。

## note自動投稿CLI「note-post」構築

**指示（ほせもやん）**
Node.js＋Playwrightでnote自動投稿CLIを作る。login / run（topics.csv→Claude生成→自己チェック→公開→posted.csv）、1日1本・STOP・--dry-run、失敗時Slack通知、セレクタはselectors.jsonに分離。まず login と --dry-run の下書き保存までを動作確認。

**Croの実装判断**
- 配置: `tools/note-post/`
- --dry-run = note下書き保存まで行い公開しない。topics.csvは未処理のまま、1日1本の枠も消費しない（posted.csvには `dry_run` で記録）
- 自己チェックNG（本番）も1日1本の枠を消費する（同じトピックでAPIを連打しないため）
- 本文はMarkdown→HTMLに変換し、エディタへ貼り付けイベントで流し込む（見出し・リスト・太字を保持）
- モデル: claude-opus-5（環境変数で変更可）、拒否時サーバー側フォールバック有効

**検証結果**
- クラウド環境ではnote.comへの通信がegressで403、APIキーも未設定 → 実画面・実APIでは未検証
- ダミーnote画面＋モックLLMで6ケース全通過（login / dry-run下書き / 公開+URL記録+1日制限 / NG→下書き / STOP / ログイン切れ / セレクタ不一致）
- selectors.jsonの値は実画面で未確認（確証なし）→ ローカルで `NOTE_HEADLESS=0 ... run --dry-run` による確認が次のアクション

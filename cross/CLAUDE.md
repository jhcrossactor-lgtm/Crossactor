# AI相棒クロス（Crossactor発信用）— Phase1

## 目的
SNS動画用の「見せる」音声対話AI。一人称視点で撮影される前提。
Phase1 = 会話＋声＋キャラ表示＋字幕。

## 構成
- フロント：単一 `index.html`（Vanilla JS。three.js はCDN）
- バックエンド：Supabase Edge Functions（APIキーはSecretsのみ。ブラウザに置かない）
  - `/chat`：Claude Messages API をストリーミング中継（SSE）
  - `/tts`：Azure Speech REST で文→mp3 を返す
- 音声認識：Web Speech API（`ja-JP`, `interimResults: true`, `continuous: true`）

## 会話
- 既定モデル `claude-haiku-4-5-20251001`
- 上位モデル `claude-sonnet-5`：画面の切替ボタン or 発話に「分析」「事業」「計算」「比較」を含む場合
- system prompt は `persona.md`＋`knowledge.md` を結合。プロンプトキャッシュ有効化
- 会話履歴は直近10往復を保持
- 返答は短く（1〜3文）。話し言葉、記号・箇条書き・URL禁止

## 音声
- ストリーム受信中、`。！？` 到達ごとに文単位で `/tts` → 順次再生キュー
- 最初の一文を最優先で再生開始（体感遅延を最小化）
- 再生中は音声認識を停止、再生終了で再開（自己応答防止）
- getUserMedia は `echoCancellation: true`
- 割り込み：再生中にスペースキー or 画面タップで即停止→聞き取りへ
- 声：`config.js` で voice名・style・rate を変更可能に

## 画面
- 表示先：15インチノートPC、16:9（1920×1080）ブラウザ全画面。一人称視点で画面ごと撮影される
- 世界観：画面の奥に「クロスの部屋」があり、クロスがその中で過ごしている（画面＝部屋を覗く窓）

### 部屋（3D）
- three.js で構築。ローポリ・トゥーン調（2Dキャラと画風を揃える）。夜の設計事務所風
- 配置：デスク（PC・モニター）、ソファ、夜景の窓、建築模型、壁モニター。天井際に紫の間接照明
- 家具は `assets/room/*.glb` で差し替え可能。未用意はプリミティブで仮置き
- カメラ：状態に応じて各スポットへゆっくり移動（ドリー）＋常時わずかな揺れで奥行きを出す
- 壁モニター：数値・グラフ・ログが流れるダミー表示（Canvasテクスチャ）

### クロス（2D）
- 2D立ち絵を部屋の中にビルボード配置（常にカメラを向く板）
- ポーズ3種：`sofa`（くつろぎ）／`desk`（作業）／`front`（こちらを向いて話す）
- 各ポーズは `assets/chara/<pose>/` に `base.png`, `eyes_open.png`, `eyes_closed.png`, `mouth_0〜3.png`
- まばたき：ランダム間隔で目の差し替え
- 口パク：TTS再生音量（AnalyserNode）→ mouth_0〜3 を切替
- ポーズ移動はフェードで切替（歩行アニメ不要）
- 素材未作成の間は仮画像で開発し、差し替えはファイル置換のみで済むこと

### 状態と演出
| 状態 | クロス | カメラ |
|---|---|---|
| idle | ソファで休憩 | 部屋全体の引き |
| listening | frontへ移動、こちらを向く | クロスに寄る |
| thinking | desk、考え込む | デスク寄り |
| speaking | front、口パク | クロスに寄る |
| working | desk、作業 | デスク→情報表示へ |
- 起動：発話に「クロス」を含むとidle→listening（誤反応は仕様として許容）。一定時間無発話でidleへ戻る
- 情報表示モード：working中や回答に表・数値がある時、画面全体に情報パネルを重ねる（部屋は背後でぼかす）。表示終了で部屋に戻る。Phase1はダミー内容でよい

### 対応端末とスキン（2026-09-26 追加）
- PCでもスマホでも同一の16:9画面を出す。スマホは横持ちで使う（PWA導入時は横向き固定）
- 画面スキンは `config.js` の `skin` で切替：`room`（3Dの部屋＋2Dクロス）／`orb`（Jarvis風の発光球体。音量・状態で脈動）。画面上にも切替ボタンを置く
- `orb` は見た目の選択肢であると同時に、低スペック端末向けの軽量モードを兼ねる
- 将来パッケージ販売するため、キャラ名・人格・声・色・スキンは設定ファイルのみで差し替え可能に保つ。コードに固有名を埋めない
- 顧客分離は当面「1顧客1 Supabaseプロジェクト」。マルチテナント化は Phase3 以降で判断

### 共通
- 字幕：画面下1/3に大きく。ユーザー発話（認識途中も表示）とAI返答（ストリーム表示）を色分け。`S`キーで表示ON/OFF
- 文字は最小28px。細線・小さい文字は撮影で潰れるため禁止
- キャラ名・Crossactorロゴは画面隅に小さく
- 主要要素は画面中央70%に収める

## 設定ファイル
- `config.js`：キャラ名、voice、モデル名、キーワード、色
- `persona.md`：性格・口調・NG
- `knowledge.md`：Crossactor事業情報（公開して問題ない内容のみ）

## 禁止
- クライアント名・物件・個人情報を knowledge.md や画面ダミーデータに入れない
- APIキーのフロント埋め込み

## 完了条件
1. 話しかけ→字幕表示→AIが声で返答、が連続5往復破綻しない
2. 発話終了から最初の音声まで体感2秒以内
3. AIの声を自分で拾って会話が暴走しない
4. 再生中に割り込める
5. 15インチ画面を1m離れてスマホ撮影し、字幕が読める・クロスの状態変化が分かる
6. idle→呼びかけ→回答→idle のカメラ移動が破綻なく繋がる

## 以降（Phase1完了後）
- 素材生成：`scripts/gen_image`（OpenAI画像API、キーは.env）でキャラ差分・部屋画像を生成し assets/ へ保存
- Phase2：壁モニター・情報表示モードに実データを連携
- Phase3：tool use で作業デモ（容積計算・配置図表示）。金額・送信・公開系は実行前に確認ゲート

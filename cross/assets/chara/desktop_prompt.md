# デスクトップ側で ChatGPT に 32 案を作らせるプロンプト

使い方：
1. **A をそのまま** デスクトップで動かしている Claude（Cowork／Claude Desktop）に貼る
2. Claude が ChatGPT を操作して 1 枚ずつ生成・保存する
3. 自分で ChatGPT に貼る場合は **B の共通指示を 1 回**、続けて **C を 1 案ずつ** 送る

---

## A. Claude Desktop（Cowork）に貼るプロンプト

```
AI相棒「クロ」のキャラクター候補画像を ChatGPT で 32 枚作って保存してほしい。

【準備】
- プロンプトは G:\ClaudeLocal\cross\assets\chara\prompts.json にある（common = 共通指示、items = 32 案）。
  無ければ先に PowerShell で G:\ClaudeLocal\cross\scripts\update.ps1 を実行してから読む。
- 保存先：G:\ClaudeLocal\cross\assets\chara\candidates\（無ければ作る）
- ファイル名：NN_slug.png（例 01_anime_glasses_navy.png）。items の no と slug をそのまま使う。

【手順】
1. Chrome で https://chatgpt.com を開く（ログイン済みのプロファイルを使う。ログイン情報を聞いたり入力したりしない）。
2. 新しいチャットを開き、最初に common の文章を 1 回だけ送る。
3. items を 01 から順に 1 案ずつ送る。1 回のメッセージに 1 案だけ。複数を同時に頼まない。
   送る文面は「{no}案目。{prompt}」の形。
4. 画像が出たらダウンロードして上のファイル名で保存し、次の案へ進む。
5. 生成の上限や「しばらく待って」と出たら、その時点で止めて「何番まで保存できたか」を報告する。
   既に candidates に存在する番号は飛ばす（再開できるように）。
6. 32 枚終わったら、candidates フォルダのファイル一覧と、失敗した番号を報告する。

【やらないこと】
- ChatGPT 以外のアプリやサイトは触らない。
- プロンプト本文を勝手に変えない（ChatGPT が拒否した時だけ、表現を少し和らげて 1 回だけ再試行し、その旨を報告）。
- 画像をどこかに投稿・共有しない。保存のみ。
```

---

## B. ChatGPT に最初に 1 回送る共通指示

```
これから「クロ」というキャラクターの候補画像を作ります。
設定：日本人・30歳・男性・建築士のAI。会社のAI CEO。落ち着いた自信のある表情で、口角を少しだけ上げる程度。口は閉じる。上半身、正面〜やや斜め、顔を手や小物で隠さない。黒髪。文字は入れない。
1回のメッセージにつき1枚、毎回同じ人物として描いてください。縦長（4:5）で、文字は入れないでください。
```

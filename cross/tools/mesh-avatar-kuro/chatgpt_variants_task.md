# デスクトップの Claude に ChatGPT を操作させて差分絵 7 枚を作る

Claude デスクトップアプリ（Cowork、コンピュータ操作 or Claude in Chrome が有効）で新しいチャットを開き、
下の A をそのまま貼る。ChatGPT にはログイン済みの Chrome を使わせる。

---

## A. 貼るプロンプト

```
Mesh Avatar Studio 用の差分絵 7 枚を、ChatGPT の画像編集で作って保存してほしい。

【ファイル】
- 元絵：G:\ClaudeLocal\mesh-avatar-studio\projects\kuro\source.png（1122×1402、透過 PNG）
- マスク：G:\ClaudeLocal\mesh-avatar-studio\projects\kuro\variant-requests\<差分名>\mask.png
- 参照：デスクトップの「未来派ホログラム執事 キャラクターシート」の PNG
- 送る文：G:\ClaudeLocal\cross\tools\mesh-avatar-kuro\chatgpt_variants_task.md の B（差分ごとに 1 本）
- 保存先：%USERPROFILE%\Downloads\kuro-variants\<差分名>.png（フォルダが無ければ作る）

【差分名（この順）】
eyes_closed, eyes_half, eyes_smile, mouth_a, mouth_a_half, mouth_i, mouth_o

【手順（差分ごとに繰り返す）】
1. Chrome で https://chatgpt.com を開き、新しいチャットを作る（ログイン情報は聞かない・入力しない）。
2. 元絵・その差分の mask.png・キャラクターシートの 3 枚を添付する。
3. B のその差分の文をそのまま送る。文は変えない。
4. 画像が出たら、次を目で確認する：
   - 眼鏡のフレーム・髪・服が元のままか（目の差分）／鼻・顎の輪郭が元のままか（口の差分）
   - 指示どおりの目・口になっているか
   崩れていたら同じチャットで「部分編集です。マスクの外側は元のまま、マスクの内側だけ直してください。眼鏡と髪は変えないでください」と 1 回だけ送り直す。それでも駄目なら次へ進み、報告に残す。
5. 画像をダウンロードし、保存先に <差分名>.png で保存する。
6. 既に保存先にあるファイルは飛ばす（途中から再開できるように）。

【終わったら】
7. G:\ClaudeLocal\mesh-avatar-studio で、保存できた差分ごとに
   uv run tools/merge-variant.py projects/kuro <差分名> "%USERPROFILE%\Downloads\kuro-variants\<差分名>.png"
   を実行し、最後に
   uv run tools/build-sprites.py projects/kuro
   npm run render-poses -- projects/kuro
   を実行する。合成後に目や口が二重に見える差分があれば、merge-variant.py の --shift dx dy でずらして合わせる。
8. projects/kuro/review/ の目閉じ・口のコマを見て、残った虹彩の点・まつ毛の二重線・口の破綻を報告する。

【やらないこと】
- ChatGPT と上のフォルダ以外を触らない。画像を他のサービスに送らない。
- ChatGPT が生成上限で止まったら、その場で止めて「どこまで保存したか」を報告する。

【報告】
- 保存できた差分／できなかった差分とその理由
- build-sprites の結果（受理された差分）
- review で残っている不自然な箇所
```

## B. ChatGPT に送る文（差分ごとに 1 本。添付は毎回 3 枚）

### eyes_closed
```
添付の source.png（1122×1402px、透過背景の2Dアバター立ち絵）を「画像編集」で部分修正してください。これは描き直しではなく部分編集です。

やること：両目を自然に閉じる。片目につき上まつ毛の線1本だけの、きれいな閉じ目にする。線の太さは元の上まつ毛と同じ。虹彩と白目は完全に消す。閉じ目の位置は元の目の中心より少し下。

守ること：
・mask.png の透明な部分だけを描き直し、不透明な部分は1ピクセルも変えない。
・眼鏡のフレームとレンズの縁、眉、髪、肌色、顔の輪郭、服、透過背景はそのまま。
・出力は source.png と完全に同じ 1122×1402px の RGBA PNG。切り抜き・リサイズ・位置ずらし禁止。
・絵柄はキャラクターシートどおり（硬質で清潔な線、青いホログラムの光沢）。
・変更はマスクの縁から4ピクセル以上内側に収める。
```

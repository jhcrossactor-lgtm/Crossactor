# クロの rig 調整メモ（VTuber 的な滑らかさ）

目標：待機中は小さくゆっくり、首振りは動きすぎず、髪や飾りが遅れて追従、まばたきは間隔に揺らぎ、口パクは母音で破綻しない。

## まず知っておくこと：どこに何があるか

Mesh Avatar Studio では「動きの量」は 2 か所に分かれている。

| 何を決めるか | 場所 | 触ってよいか |
|---|---|---|
| 顔・髪・体の **位置と範囲**、首振りの最大移動量、髪バネの硬さと振れ幅 | `projects/kuro/rig.json`（`docs/rig-fields.md`） | エディタで調整する前提の値。ここが本線 |
| 待機中の揺れの振幅・周期、呼吸の周期、まばたき間隔、追従バネ | `src/engine/motion.js` / `physics.js` の定数 | ツール本体。**改変しない**。公開 API と配信ページ側で抑える |

つまり「呼吸をゆっくり」「まばたきの揺らぎ」は rig.json には項目が無い。本体を書き換えずに済ませるため、クロ専用の配信ページ `stream-fx.html` が公開 API だけで振幅を落とす（下の B）。

## A. rig.json 側（描いた後にエディタで追い込む値）

数値は画像サイズに対する割合で考える。`W` = 画像幅 px、`H` = 画像高さ px。
「起点」は `docs/agent-guide.md` と `samples/miko-qipao/rig.json` の既定。実際の値は作業時に **変更前→後で記録** する。

| 項目 | 起点（手順書の既定） | クロ推奨 | 狙い |
|---|---|---|---|
| `head.shiftX` | W × 3〜4% | W × 2.5〜3% | 首振りの横移動を控えめに |
| `head.shiftY` | H × 2〜3% | H × 1.8〜2.2% | 上下の見上げ・見下ろしを控えめに |
| `head.maxRoll` | 0.15 rad | 0.11〜0.12 rad | 首かしげの角度を小さく |
| `head.weightBand` | 顎下〜鎖骨 | 顎下〜鎖骨（やや長め） | 首の付け根のねじれを滑らかに |
| `body.maxRoll` | 0.035 rad | 0.028〜0.03 rad | 体の揺れを小さく |
| `body.breathBand` | 胸上〜画像下端 | 同じ | 呼吸の範囲は変えない（振幅は B で落とす） |
| `strands[*].k` | 1 | 0.75〜0.85 | バネを柔らかく → 頭より遅れて動く |
| `strands[*].max` | 7〜12 px | 10〜14 px | 遅れて追従したぶん振れ幅の上限を少し広げる |
| `strands[*].sigma` | 房の幅の半分 | 同じ〜やや広め | 房の境目が割れないように |
| `accessories[*].split` | 0.4 | 0.4 | 飾りが無ければ省略 |
| `mesh.fine.cell` | 7 | 6〜7 | 口パクで口元の格子が粗く見えたら 6 に |
| `mouth.area.ry` | 唇よりやや大きく | 顎に届かない範囲で大きめ | 「あ」の描き分けが顎を引っ張らないように |

**手順**：まず起点で作る → ポーズ確認で破綻を直す → 上の表に寄せる、の順。最初から小さくすると「動いていない」ように見えて、どこが悪いか分からなくなる。

## B. 配信ページ側（本体を触らずに落ち着かせる）

`stream-fx.html` の URL パラメータ。既定値がクロ向けに落ち着かせた値になっている。

| パラメータ | 本体の既定（相当） | クロ既定 | 何が変わるか |
|---|---|---|---|
| `calm` | 1.0 | **0.65** | 待機中の首振り（±10°→±6.5°）、見上げ（±6°→±3.9°）、首かしげ（±10°→±6.5°）、体の揺れ（±5°/±4°→±3.3°/±2.6°）、呼吸の深さ（×0.65）、小さな待機モーション全体を 0.65 倍 |
| `sway` | 1.0 | **1.3** | 髪・飾りのバネを柔らかく、減衰も弱め → 頭に遅れてついてくる。振れ幅上限 ×1.3 |
| `talk` | 1.0 | **0.6** | 発話中に声で首が動く量 |
| `motions` | 1 | **1** | うなずき・首かしげなど大きめの反応。うるさければ `0` |

仕組み：`avatar.setParameters({angleX:0, …, breath:0}, 1 - calm)` で待機値を 0 に向けて `(1-calm)` だけ引き寄せる（= 振幅 × calm）。`setSwayGain(sway)`、`setTalkGain(talk)` は本体の公開 API。

### 変えられないもの（本体の定数。記録だけ）

| 項目 | 本体の値 | 備考 |
|---|---|---|
| まばたき間隔 | 1.8〜6.0 秒のランダム、18% で二度まばたき、1 回 0.17 秒 | 既に揺らぎあり。十分 VTuber 的 |
| 呼吸周期 | 3.2〜4.6 秒で毎回ドリフト | 既に揺らぎあり。深さだけ `calm` で浅くなる |
| 首の追従バネ | angleX/Y 剛性 55・減衰比 0.72、angleZ 45・0.75 | 「目が先、首が後、体がさらに後」になっている |
| 髪バネ | 根元→先端 剛性 [0,300,200,140]、結合 0.9、減衰 7、全体 stiff 1.7 / damp 1.6 | `sway` でまとめて柔らかくできる |

どうしても足りなければ `src/engine/motion.js` の `fbm(...) * 10` 等の係数と `blinkValue` の `1.8 + Math.random() * 4.2` を触れば済むが、本体改変になるので **ほせもやんの判断があってから**。

## C. 口パクの確認ポイント

- エディタ「口の動き」で あ・い・う・え・お・ん を 1 つずつ保持 → 顎が伸びる／唇の端が割れる なら `face.jaw.band` を顎寄りに、`face.mouth.ry` を小さく
- 描き分け画像（variant-prompts.md）が入ると口はメッシュ変形ではなく絵の差し替えになる。破綻の大半はこれで消える
- 文章再生は 7 モーラ/秒前後で確認（速すぎると形が追いつかないのは本体の仕様）

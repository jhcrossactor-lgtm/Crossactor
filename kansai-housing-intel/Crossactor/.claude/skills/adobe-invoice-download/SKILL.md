# Adobe 請求書・領収書ダウンロード スキル

## 前提条件
- Claude in Chrome が起動済みであること
- Chrome に Adobe アカウントのログイン情報が保存済みであること（または既にログイン済み）
- ダウンロード先フォルダが存在すること（デフォルト：`~/Downloads/Adobe請求書/YYYY-MM/`）

---

## 手順

### Step 1: 請求履歴ページへ直アクセス

Chromeにログイン済みの前提で、請求履歴ページへ直接移動する：

```
navigate: https://account.adobe.com/billing-history?lang=ja
```

- ページ読み込み完了を確認
- **ログイン済みの場合** → そのまま請求履歴が表示される（Step 2へ）
- **ログイン画面が出た場合** → **ユーザーにログインを依頼してから再開**（パスワードは代行入力しない）
- **ログイン後に請求履歴が表示されない場合** → 左サイドバーから「プランと支払い」→「請求履歴」を選択

### Step 2: 対象プランと対象月を確認

- 請求履歴一覧からユーザーが指定した月（デフォルト：先月分）のデータを確認
- IllustratorプランとPhotography plan (20GB)の両プランが対象
- 対象行に「請求書をダウンロード」「PDF」「領収書」等のリンクがあることを確認

### Step 3: PDFをダウンロード

- 「請求書をダウンロード」ボタン or PDFアイコンをクリック
- ダウンロード完了を確認（ブラウザのダウンロードバーまたは通知）
- 領収書が別途存在する場合は同様にダウンロード
- 両プラン分（最大4ファイル）ダウンロードすること

### Step 4: ファイルを整理

ダウンロードされたPDFを所定フォルダへ移動：

```
デフォルト保存先: ~/Desktop/Adobe請求書/YYYY-MM/
ファイル名例: Adobe_Illustrator_請求書_2026-04.pdf
            Adobe_Illustrator_領収書_2026-04.pdf
            Adobe_Photography_請求書_2026-04.pdf
            Adobe_Photography_領収書_2026-04.pdf
```

### Step 5: 完了報告

ユーザーへ以下を報告：
- ダウンロードしたファイル名とパス
- 請求金額（PDFに記載されていれば）
- 次回実行予定（翌月同時期の目安）

---

## 注意事項

- **パスワードは絶対に代行入力しない**。ログイン画面が出た場合は必ずユーザーに委ねる
- Adobe側のUI変更でメニュー構成が変わる場合がある。その際はページ内を検索して対応
- 「請求書」と「領収書」は別PDFとして提供される場合がある（両方ダウンロードすること）
- 複数プランを契約している場合、全プラン分ダウンロードすること

---

## トラブルシューティング

| 状況 | 対処 |
|------|------|
| ログイン画面が表示される | ユーザーにログインを依頼して再開 |
| 請求履歴ページが見つからない | `account.adobe.com` トップからメニューを探す |
| PDFリンクが表示されない | 当月請求がまだ確定していない可能性。翌日以降に再試行 |
| ダウンロードがブロックされる | Chromeのダウンロード設定を確認するようユーザーに案内 |

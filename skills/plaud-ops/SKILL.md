Plaud CLI（`plaud`）経由で録音を取得し、議事録化して `communications/logs/` に記録するまでを担う。

未導入の場合は [setup.md](setup.md) を先に実施する。`plaud me` が失敗したら導入が済んでいない。

## 手順

### 1. 録音を特定する

| 状況 | コマンド |
|---|---|
| 今日の会議 | `plaud today --json` |
| 直近N日 | `plaud recent -d 7 --json` |
| 名前で検索 | `plaud search "<keyword>" --json` |
| 一覧を辿る | `plaud files -p 1 -s 20 --json` |

`--json` で取得し `file_id` を確定する。候補が2件以上に絞りきれないときは、名前・日時・長さを並べてほせもやんに選ばせる。推測で1本に決めない。

### 2. 内容を取得する

既定は要約のみ。

```
plaud summary <file_id>
```

`--polished`（整形済み）、`--highlights`（要点抽出）が使える。

逐語の引用が必要、または誰の発言か特定する必要があるときだけ文字起こしに降りる。

```
plaud transcript <file_id>
```

長い会議の全文を無条件に読み込まない。要約で足りるなら要約で止める。

### 3. 議事録にする

要約・文字起こしから以下を抽出する。

- 決定事項
- 次のアクション（担当者つき）
- 未決の論点

要約に無い項目を創作しない。担当者が不明なアクションは「担当未定」と明示する。

### 4. 記録する

`communications/logs/YYYY-MM-DD.md` に既存書式で追記する（`communications/logs/2026-04-15.md` を参照）。

```
## HH:MM頃 — <会議名>

**参加者：** ...

**内容：**
...

**決定事項：**
- ...

**次のアクション：**
- ...
```

重要な意思決定があった場合は `communications/MEMORY.md` にも記録する（何を決めたか・理由・却下した選択肢）。

## 禁止事項

- 音声ファイル・文字起こし全文をリポジトリにコミットしない。議事録として要約したものだけを残す
- 議事録の外部送出（メール送信・Slack投稿・Notion保存など）は、その時点のメッセージで明示的に許可されるまで実行しない
- `~/.plaud/tokens.json` の中身を読み出したり、ログ・チャットに出したりしない
